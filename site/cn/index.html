Apell

你的小程序， 都在这里。

在 iOS、Android 和 macOS 上安装并运行小程序。模型服务配置一次即可共用，每个小程序仍有独立的本地数据。

构建 Apell ↗ 开发小程序 ↓

安装小程序，打开就能用。

从文件或 GitHub 安装
打开本地 .apel 文件，或从公开的 GitHub Release 安装。安装后，小程序会出现在启动器中。
共用模型连接
在 Apell 中管理模型服务和凭据。小程序通过宿主 API 使用你配置好的连接。
回来接着用
每个小程序都有自己的本地文件和 SQLite 数据。Companion 会保存对话，关闭界面后也能完成正在生成的回复。

在自己的仓库里发布小程序。

将网页前端和清单打包，也可以带上 Rust WebAssembly 后端。通过 Apell 的 API 使用模型、存储和设备能力。
