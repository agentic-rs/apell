Apell

你的小程序， 都在这里。

在 iOS、Android 和 macOS 上安装并运行小程序。模型服务配置一次即可共用，每个小程序仍有独立的本地数据。

开始使用

为你的设备从源码构建 Apell，然后安装第一个小程序。

从源码构建

查看构建环境要求 ↗
  • iOS在 Mac 上使用 Xcode↗
  • Android使用 Android SDK、NDK 和 Java↗
  • macOS构建独立运行的桌面应用↗

安装小程序

Apell Store ↗
在 Apell 启动器中打开 Store，添加商店的 HTTPS 地址，选择小程序后点击 Install。
.apel 文件
选择 + → Install an .apel file，打开设备上的安装包。
公开的 GitHub Release
选择 + → Install from GitHub，输入公开仓库或发行版网址。

共用模型，数据独立。

共用模型连接
在 Apell 中管理模型服务和凭据。小程序通过宿主 API 使用你配置好的连接。
回来接着用
每个小程序都有自己的本地文件和 SQLite 数据。Companion 会保存对话，关闭界面后也能完成正在生成的回复。

在自己的仓库里发布小程序。

将网页前端和清单打包，也可以带上 Rust WebAssembly 后端。通过 Apell 的 API 使用模型、存储和设备能力。
